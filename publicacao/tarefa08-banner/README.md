# Tarefa 08 — Banner Científico (versão preliminar v1)

**Trabalho:** Avaliação de Desempenho de Bancos de Dados SQL e NoSQL para Armazenamento de Dados de Sensores IoT em Ambiente de Nuvem
**Evento:** III Congresso UniSENAI-SP de Educação, Tecnologia e Inovação (04 e 05/12/2026)

## Arquivos

- `banner-v1.pdf`: versão para leitura e impressão
- `banner-v1.pptx`: versão editável

## Template utilizado

- **Fonte (referência de estilo):** Canva, https://www.canva.com/. O estilo segue pôsteres acadêmicos do Canva, mas o layout foi criado do zero, sem copiar um modelo específico.
- **Ferramenta de edição:** Microsoft PowerPoint (arquivo `.pptx`), gerado a partir de script com PptxGenJS.
- **Formato:** A0 retrato (84,1 cm × 118,9 cm), provisório.

## Justificativa da organização visual

O banner segue a ordem lógica da pesquisa. A arquitetura proposta aparece logo abaixo do título, em um fluxo horizontal (sensores, AWS IoT Core, API REST, bancos e dashboard), para que o leitor entenda o estudo antes de ler o texto. As seções são numeradas de 01 a 08 em três colunas. Os resultados deixam explícito que os experimentos ainda não foram executados.
