# Tarefa 08 — Banner Científico (versão preliminar v1)

**Trabalho:** Avaliação de Desempenho de Bancos de Dados SQL e NoSQL para Armazenamento de Dados de Sensores IoT em Ambiente de Nuvem
**Evento:** III Congresso UniSENAI-SP de Educação, Tecnologia e Inovação (04 e 05/12/2026)

## Arquivos

- `banner-v1.pdf`: versão para leitura e impressão
- `banner-v1.pptx`: versão editável

## Template utilizado

- **Fonte do template:** nenhum template externo. O layout foi criado do zero, pois o evento ainda não divulgou modelo oficial.
- **Ferramenta de edição:** Microsoft PowerPoint (arquivo `.pptx`), gerado a partir de script com PptxGenJS.
- **Formato:** A0 retrato (1,31 m × 1,89 m), provisório.

## Justificativa da organização visual

O banner segue a ordem lógica da pesquisa: introdução, problema, objetivos, metodologia, resultados parciais, considerações preliminares, referências e agradecimentos. A metodologia tem destaque próprio, com o fluxo da arquitetura em blocos (sensores, AWS IoT Core, API REST, bancos e dashboard), para que o leitor entenda o estudo rapidamente. A seção de resultados deixa explícito que os experimentos ainda não foram executados.
